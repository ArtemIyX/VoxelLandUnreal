# VoxelLand M3 authoring guide

This guide describes the current source implementation. It has not been verified by an editor build, cook, dedicated-server run, or the M3 automation suite. See [M3_Verification.md](M3_Verification.md) for the pending checks and [M3_Operators.md](M3_Operators.md) for noise and C++ operator contracts.

Create a **VoxelLand Terrain Graph**, **VoxelLand World Settings**, and optional **VoxelLand Material Setup** in the Content Browser. Assign the graph and a seed, voxel size, optional material setup, and parameter overrides to the settings asset. The material setup contains one surface material; absent or unsuitable runtime materials fall back to the engine surface material. No material palette or terrain collision is included.

Open the graph. The Graph tab provides searchable context actions and left-to-right typed pins. The Details / Parameters tab adds float, int, and bool parameters. Select the graph background to edit declarations, and select a matching parameter-reference node to set its stable parameter GUID. Parameter names must be unique ASCII identifiers, ignoring case. World overrides identify the parameter by GUID and must match its type and range. Add and Multiply support adding and removing inputs from their context menus; input order is significant.

For a starting graph, connect Position X and Position Y to Perlin 2D, multiply its output by an amplitude, then connect that value to Height to Density and connect the result to Density Output. Add an independently seeded fBm 2D or Value 2D branch through Add to vary the height. Noise coordinates are in cm and frequency is inverse cm. Negative density is solid. Node GUID and salt affect the noise seed; changing node positions does not. The planned example asset has not yet been created.

A single Smooth Density node may sit directly before Density Output. Its density input is the pure field; Enabled and Strength accept defaults or direct bool and float parameter references. Strength is in [0,1]. The filter evaluates a 37-cubed source lattice for each 35-cubed chunk, uses a one-cell 27-sample box filter over quantized density, and blends with uint16 fixed-point strength. Disabled and zero strength use the original field. Do not chain filters or consume a filtered intermediate elsewhere.

Use Compiler Results to compile and inspect errors. Saving attempts to compile the source and stores a versioned program with source and program fingerprints. A failed compile leaves the graph editable and the old preview labeled stale; runtime initialization rejects stale or invalid payloads. Cook failure behavior still needs verification in the target engine. Power supports positive finite bases and exponents, and bounded integral exponents for negative bases; its numerical contract and unverified cross-host limits are documented in M3_Operators.md.

The Preview tab provides a seed, a material selector, a world-settings selector, bounded XY/Z radius, transient settings and overrides, and a reset camera control. Selected settings are duplicated for preview, so adjustments there do not save back to the asset. Preview chunks are generated and meshed on the CPU, then displayed through Unreal's render pipeline. The status reports stale, compiling, generating, error, or ready and displays timings; those timings have not been benchmarked. Material changes update the existing preview rather than rebuilding density.

At runtime, place a VoxelLandWorld actor and explicitly call `InitializeFromSettings` after BeginPlay from a manager or Blueprint. A true return means the asynchronous request was accepted, not that generation has completed. Observe `OnInitializationFinished`, `bInitializing`, and `LastInitializationError`; `CancelInitialization` cancels a pending request. No generation starts automatically in BeginPlay. The request copies graph, program, settings and overrides before worker execution; a changed source or settings snapshot rejects the result. A dedicated server uses the data-only path and skips material loading; its actual target build and module loading still require verification. `Shutdown` tears down generation.
