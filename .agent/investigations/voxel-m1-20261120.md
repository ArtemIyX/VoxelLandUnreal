## Diagnosis and relationship flow

This is greenfield implementation, not a localized bug. The existing module separation is appropriate once Algo publicly depends on Data, privately depends on UnrealFastNoise2, and Uncooked privately depends on Data/Algo. Native wrappers that use UObjects must not enter generation. Correct flow: host/module startup loads dependency and records native availability -> actual worker validates draft -> immutable program -> immutable generator snapshot resolving profile/seed/parameters -> worker creates exclusive context/scratch/native nodes -> GenerateChunk -> sample batches -> finite checks -> explicit quantization -> canonical density hash -> immutable completed chunk. Snapshot/program may cross threads; context may not.

### Data and opcode contract

Version one program draft contains format uint32, register count, ordered instructions/constants, typed parameter declarations with stable normalized string names/defaults, ordered seed slots (FGuid, uint32 salt), and ordered native noise configurations. Public validated program exposes const getters and cannot be constructed/mutated except through validator. Publish only TSharedPtr/Ref<const ..., ESPMode::ThreadSafe> without leaking mutable aliases; copy draft/profile into owned state. Opaque context belongs to Algo, not shared Data.

Fix explicit uint16 opcode numbers. Instruction fields: opcode, Dst, A/B/C register indices, uint32 immediate. Define operand meanings in header:

- LoadPosX/Y/Z, LoadConstant(Imm), LoadFloatParameter(Imm) write Dst.
- Add/Subtract/Multiply/Divide/Min/Max read A/B; Abs/Negate read A; include optional Lerp/Clamp only if implemented and validated completely.
- Plane: A/B/C are position coordinates, Imm references four consecutive finite constants normal xyz and offset, normal must be unit length (or normalized once during validation with canonical result). Sphere: A/B/C position, Imm radius constant >0; Box: A/B/C position, Imm starts three positive half extents. Translations are authored with ordinary subtract instructions.
- HardUnion=min(A,B), HardSubtract=max(A,-B), HardIntersect=max(A,B).
- Perlin2/Fbm2 read A/B, Perlin3/Fbm3 read A/B/C; Imm indexes native noise configuration. Config contains seed slot index, frequency float source (constant or typed parameter slot), fBm octave int32 source, gain/lacunarity float sources. Frequency positive, octave count 1..16, gain 0..1 and lacunarity >=1 finite; establish these bounds in header and validate both defaults and resolved overrides.
- StoreDensity reads A and copies result immediately to separate output scratch; exactly one store per program. Reject unknown opcode and version. An explicit LoadIntParameter is optional: octaves consume actual int32 slot directly so no precision-losing float conversion is needed.

Validator tracks initialized registers in instruction order; checks only operands applicable to each opcode, destination bounds, read-before-write, constants/config ranges, seed slot bounds and duplicate stable IDs, normalized parameter duplicates/types/defaults and exactly one output. Bound register count to a documented safe limit and prevent register-count * batch-size integer overflow. Errors contain code, message, instruction index and parameter name/index when applicable. Fail before allocating worker scratch on game-thread entry.

### Backend and native availability contract

Separate VM {Auto, Scalar, Simd4} and native {Auto, Scalar, SSE2} requests and report actual selections. Auto VM selects four-lane only where guarded code/CPU supports it, otherwise scalar. Compile macro VOXELLAND_ENABLE_VM_SIMD default 1, with build-rule option documented to compile 0. Explicit Simd4 unsupported -> typed BackendUnavailable; Auto -> scalar. Select once in context setup, outside samples.

Algo StartupModule calls LoadModulePtr<IModuleInterface>("UnrealFastNoise2") and checks runtime library availability without calling native symbols first. Vendor does not expose its handle: private Algo can use platform GetDllHandle on the dependency plugin library path (Plugins private module dependency for IPluginManager) and own that extra reference through module lifetime. Resolve known exported fnNewFromEncodedNodeTree/fnGetSIMDLevel or required symbols if appropriate before any C++ call. Startup failure records availability; setup returns typed NativeLibraryUnavailable. Never load/unload modules or native DLLs inside generation. Keep native headers private and module-private availability synchronization trivial.

Native Auto pins SSE2 only on supported x64 and otherwise Scalar. Check COMPILED_SIMD_LEVELS & requested & FastNoise::SUPPORTED_SIMD_LEVELS and CPUMaxSIMDLevel before factories. Scalar override with bundled x64 headers returns BackendUnavailable before factory. Scalar-enabled replacement requires matching native headers/config/library from same upstream revision; document it as a pending external dependency, do not modify FastNoise submodule. New(level) is a cap: verify non-null and exact GetSIMDLevel for every node and return typed error on mismatch.

One private process-wide FCriticalSection protects all native node create/configure/reference-copy/destruction operations, including temporary SmartNode conversions from SetSource and context arrays clearing. This is a lifecycle guard, not a mutable cache. Construct all nodes in context setup and destroy them inside the guard on same owning worker; parallel sampling holds no global lock. Context destructor performs explicit guarded reset/clear before members destruct outside the lock. No SmartNode leaks into shared snapshots.

### Ownership, seeds, canonical hashing

Generator snapshot has immutable program, copied profile, resolved float/int arrays, derived signed seeds and backend options. Worker context records FPlatformTLS::GetCurrentThreadId and generator identity; entry rejects wrong worker/context before using buffers. Public Create/Validate/Generate paths return typed GameThreadNotAllowed immediately. Lifetime contract: context must be created/used/destroyed in one worker invocation; destructors enforce with checks. Shared generator has no native handles.

Use exact uint64 wrapping Mix64/HashGuid/DeriveNodeSeed from design. Native seed maps low uint32 bits to signed int32 without implementation-defined cast: bits <=INT32_MAX -> int32(bits), otherwise int32(int64(bits)-4294967296). Adding seed slots never changes derivation of existing GUID/salt. Program fingerprint may change when layout changes; existing noise output must not.

Canonical writer appends explicit little-endian unsigned widths; signed integers serialize modulo their corresponding unsigned width; floats copy IEEE754 bits via FMemory::Memcpy. Normalize -0 to +0 or explicitly preserve it consistently; reject non-finite values. Parameter identifiers use a documented restricted ASCII case-insensitive grammar normalized to lowercase FString and UTF8 length+bytes, avoiding locale-dependent Unicode case rules/FName indices. Instruction register and slot indices are semantic, so ordered layout is hashed in fixed input order. Include format version, register count, all opcode and operand fields, constants, parameter normalized names/type/default bits, GUID A/B/C/D and salts, all noise configuration/source-discriminant fields. Never hash raw structs or map memory/iteration. Overrides resolve by program declaration order, maps used only for lookup/validation.

Density hash is FXxHash64::HashBuffer over 85750 explicit low-byte/high-byte samples in X-fastest order; use returned .Hash numeric uint64. Program fingerprint is a separate hash; chunk hash is density-only. Complete chunks publish const handles only after every sample and hash succeeds.

### VM/grid/quantization

Scratch reserves NumRegisters*256 SoA float slots plus position/noise/output/canonical-byte buffers and reuses capacity across batches/chunks. Scalar supports every opcode; vector arithmetic applies four-lane exact operations with scalar tail. Scalar and SIMD operation order must be identical; avoid reciprocal-estimate division/FMA/reassociation. Analytic complex ops can call scalar per sample in both paths. Validate finite arithmetic/noise output before it can propagate to undefined native integer conversion.

For sample linear i: X=i%35; Y=(i/35)%35; Z=i/(35*35). Each lattice axis int64(key.axis)*32+local-1, multiply in double by profile voxel size, then check finite float conversion. LOD>0 returns UnsupportedLod. Quantization double distance/voxel*1024; reject non-finite distance/scale; saturate first; floor(s+0.5) for nonnegative or ceil(s-0.5) for negative; cast only after bounds proven. Range must stay valid at +/-32768/32767 and exact half ties. Consider overflow of scaled noise positions and octave lacunarity before vendor conversion to integer lattice: reject out-of-domain finite values rather than invoke undefined conversion.
